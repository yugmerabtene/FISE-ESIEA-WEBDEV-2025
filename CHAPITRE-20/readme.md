## Chapitre 20 : Projet Final et Bonnes Pratiques

### Objectif
Ce chapitre consiste à réaliser un projet complet qui synthétise l'ensemble des compétences acquises durant la formation.

### Consignes
1. Choisir un sujet libre (site vitrine, e-commerce, blog, etc.)
2. Rédiger un cahier des charges complet
3. Créer une charte graphique
4. Maquetter l'application
5. Développer le frontend en HTML5/CSS3/Bootstrap
6. Développer le backend en PHP/MySQL
7. Versionner le code avec Git
8. Déployer l'application avec Docker

### Critères d'évaluation
- Qualité du code et respect des bonnes pratiques
- Utilisation de Git avec des commits clairs
- Design responsive et accessible
- Sécurité (XSS, SQL injection, CSRF)
- Présentation orale du projet
